# Googleサービス連携 予約受付自動化ツール

Googleフォームの予約回答をもとに、カレンダーへの予定登録・予約完了メール送信・処理結果の記録を自動化します。

[作品一覧](https://github.com/moedaichi0629-ai/landing-page) · [ポートフォリオ](https://moedaichi0629-ai.github.io/)

## 解決する課題

**想定利用者：** Googleフォームでオンライン相談などの予約を受け付ける小規模事業者

予約を受け付けるたびに予定登録・確認メール・処理状況の記録を行う手間。

## 主な機能

- フォーム回答をGoogle Sheetsへ保存（フォームの標準機能）
- GASでGoogle Calendarに60分の予定を登録
- Gmailで予約完了メールを送信
- 処理結果・エラー記録と選択行の手動再実行

## デモ・利用方法

公開デモはありません。Googleアカウント上にフォーム・シート・GASを設定して使用します。

## 使用技術

Google Forms / Google Sheets / Google Apps Script / Google Calendar / Gmail

## 工夫した点

CalendarイベントIDを保存し、同じ回答行の再実行による予定の二重作成を防ぎます。

## 現在の実装範囲

同じ時間帯への複数予約はブロックしません。予約枠管理・変更・キャンセルは未実装です。

## 1. 概要

Googleフォームからオンライン相談予約を受け付け、フォーム送信後に以下を自動化するツールです。

- Google Sheetsへの回答保存（Googleフォームの標準機能）
- Google Calendarへの予定登録
- Gmailでの予約完了メール送信
- 処理結果・エラーのGoogle Sheetsへの記録
- 手動再実行（Google Sheetsのカスタムメニューから）
- 同一フォーム回答（同一行）に対するCalendar二重登録防止

## 2. システム構成

```
Googleフォーム
  ↓
Google Sheets
  ↓
Google Apps Script
  ├─ Google Calendar
  └─ Gmail
```

## 3. 使用技術

- Google Forms
- Google Sheets
- Google Apps Script

追加の有料サービス・外部サーバーは使用していません。

## 4. Google Sheets列構成

| 列 | 項目 |
|---|---|
| A | タイムスタンプ |
| B | お名前 |
| C | メールアドレス |
| D | 予約日 |
| E | 予約時間 |
| F | 相談内容 |
| G | 処理ステータス |
| H | CalendarイベントID |
| I | メール送信日時 |
| J | エラー内容 |

A〜Fはフォーム回答により自動入力されます。G〜Jはスクリプトが書き込む管理列です。

## 5. セットアップ

- **フォームとSheetsの連携**: Googleフォームの「回答」タブから回答先スプレッドシートを作成・連携します（Googleフォームの標準機能）。
- **Code.gsの配置**: 回答先スプレッドシートで「拡張機能 > Apps Script」を開き、コンテナバインドスクリプトとして `gas/Code.gs` の内容を配置します。
- **タイムゾーン（Asia/Tokyo）**: スプレッドシートの「ファイル > 設定」と、Apps Scriptプロジェクトのタイムゾーンを両方ともAsia/Tokyoに設定します。コード内の日時計算（`buildReservationDateTime` 等）もAsia/Tokyo前提で実装されています。
- **インストール型「フォーム送信時」トリガー**: Apps Scriptエディタの「トリガー」画面から、イベントのソース「スプレッドシートから」、イベントの種類「フォーム送信時」、実行する関数 `onFormSubmit` を指定してトリガーを追加します。
- **onFormSubmitの使用**: フォーム送信時トリガーの実行関数は `onFormSubmit` です。この関数が送信された行を特定し、共通処理関数 `processReservationRow` を呼び出します。
- **初回のGoogle権限承認**: 初回実行時、Calendar・Gmail・Sheetsへのアクセス権限を求める承認画面が表示されます。スクリプトを実行するGoogleアカウントで承認してください。

## 6. 通常の動作

1. お客様がGoogleフォームから予約を送信する
2. フォームの回答がスプレッドシートに1行追加される（Googleフォームの標準機能）
3. インストール型トリガーにより `onFormSubmit` が呼び出される
4. `processReservationRow` が対象行を処理する
   - お名前・メールアドレス・予約日・予約時間・相談内容を取得する
   - D列（予約日）・E列（予約時間）から予約開始日時（Asia/Tokyo）を生成する
   - 過去日時でなければ、デフォルトCalendarへ60分の予定を登録し、イベントIDをH列へ保存する
   - 予約者へ予約完了メールを送信する
   - 処理結果をG〜J列へ記録する

## 7. 手動再実行

Google Sheets上で対象の予約行（データ行）を選択し、以下のカスタムメニューから再実行します。

```
予約管理
→ 選択した予約を再実行
```

- 選択行が1行目（ヘッダー行）の場合、または選択行にお名前が入力されていない場合は処理を行わず、アラートを表示します。
- H列にCalendarイベントIDが既に存在する場合、新しいCalendar予定は作成せず、未完了の処理（メール送信など）のみ再実行します。これにより同じフォーム回答に対するCalendarの二重作成を防ぎます。
- 手動再実行は、フォーム送信時と同じ `processReservationRow` を呼び出す実装になっており、処理ロジックの重複はありません。

## 8. エラー処理

`gas/Code.gs` の実装に基づく整理です。

| ケース | 条件 | G列 | H列 | I列 | J列 |
|---|---|---|---|---|---|
| 入力不足 | お名前・メールアドレス・予約日・予約時間・相談内容のいずれかが空 | エラー | 空欄 | 空欄 | エラー内容 |
| 過去日時 | 予約日＋予約時間が処理時点以前（Calendar未登録の行のみ判定） | エラー | 空欄 | 空欄 | エラー内容 |
| Calendar登録失敗 | Calendar登録処理自体が失敗 | エラー | 空欄 | 空欄 | エラー内容 |
| メール送信失敗 | Calendar登録成功後、メール送信が失敗 | Calendar登録済み・メール未送信 | イベントID | 空欄 | エラー内容 |

いずれのエラーでも管理者への通知メールは送信しません（`docs/02_requirements.md` 10章の確定仕様）。

## 9. スコープ外

以下は今回実装していません。

- 予約の重複防止（同日時への複数予約はブロックしません）
- 予約可能枠の管理
- 予約変更・キャンセル
- Google Meet等のオンライン会議URLの自動発行
- 管理者へのエラー通知
- 自動リトライ（エラー時の自動再実行）
- 外部有料サービスの利用

## 10. 注意事項

- Calendar登録先は、GASを実行・認可したGoogleアカウントのデフォルトカレンダーです（共有カレンダー等は対象外）。
- 過去日時判定は、Calendar未登録の行（H列が空の行）に対してのみ行われます。既にCalendar登録済みの行（H列にイベントIDがある行）を再実行する場合は、この判定を行わずメール送信のみ試行します（`gas/Code.gs` の `processReservationRow` 内コメント参照）。この挙動は `docs/02_requirements.md` に直接の記載はなく、実装判断です。
- 同じ内容のフォーム回答が複数回送信された場合も、それぞれ別の予約として処理されます（重複チェックは行いません）。同日時の複数予約も許可されます。
- 相談内容・お名前に含まれる改行や記号は、変換せずそのまま文字列として扱われます。
- 秘密情報（APIキー・トークン等）はコードに記載していません。
